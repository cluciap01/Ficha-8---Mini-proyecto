# Frontend

    -El frontend es la parte de la página web que ve y utiliza el usuario. En YouTube podemos encontrar:

        -HTML: organiza los elementos de la página, como los vídeos, botones, menús, títulos y comentarios.
        -CSS: se encarga del diseño visual, los colores, los tamaños y la distribución de los elementos.
        -JavaScript: permite las funciones interactivas, como reproducir vídeos, buscar contenido, abrir menús o interactuar con los botones.
    
    -Algunos elementos del frontend son:
        -La barra de búsqueda.
        -El reproductor de vídeo.
        -El menú lateral.
        -Los botones de «Me gusta» y suscripción.
        -La sección de comentarios y recomendaciones.

# Backend

    -El backend es la parte que funciona en los servidores y que el usuario no ve directamente.
    -En YouTube se encarga de tareas como:
        -Gestionar las cuentas de usuario.
        -Almacenar y gestionar la información de los vídeos.
        -Procesar las búsquedas.
        -Guardar comentarios, suscripciones y listas de reproducción.
        -Gestionar las recomendaciones de vídeos.
        -Controlar el acceso a los contenidos.
    -También intervienen sistemas de almacenamiento y distribución de vídeos para que puedan reproducirse correctamente.
